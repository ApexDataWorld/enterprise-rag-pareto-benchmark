# Code of Conduct

This project expects professional, respectful collaboration.

Contributors should:

- discuss technical disagreements constructively;
- avoid personal attacks or discriminatory language;
- respect privacy and confidentiality;
- avoid posting secrets, credentials, customer data, PHI, or proprietary data;
- keep issue and pull request discussions focused on the benchmark.

Project maintainers may close or edit issues that include abusive content,
secrets, or confidential data.
